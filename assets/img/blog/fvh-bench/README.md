## Evidence and provenance

Primary source: Zhu, Z., Liu, Y., Lyu, S., and Wu, B. *FVH-Bench: Evaluating Image Generator Safety Beyond Overtly Harmful Imagery*. [arXiv:2610.37722v1](https://arxiv.org/pdf/2610.37722v1).

- `hero-diagram.png`: generated with built-in imagegen. Generic artifact forms illustrate the five visual functions; these are not experimental outputs. Exact prompt: `hero-prompt.md`.
- `construction.svg`: simplified §3.3 / Appendix A.1 workflow. Four agent roles followed by human curation; 669 of 750 initial candidates retained.
- `metrics.svg`: §4.1 definitions and denominators. RR applies to all prompts; PIC, THR, and HAU apply to generated images with valid assessments.
- `main-results.csv` / `.svg`: three headline results reported in §4.2 and supported by Table 1: mean RR 2.45%, mean THR 4.46, four models with mean HAU > 4. The first two values are averages across 11 generators, rounded to two decimals. These are numeric callouts, not lengths on a shared scale.
- `detector-results.csv` / `.svg`: four selected configurations from Table 2, comparing General Safety Policy and Condition-Decomposed detection with both backbones. Recall over 500 harmful images; FPR over 200 benign controls. Plot uses 0–100% and direct labels. No uncertainty intervals are reported in the source table or invented here.

Tables 1–2 were checked against the rendered source PDF. All generator cells and detector values were checked against extracted PDF text before selecting the headline results. The article intentionally presents the main results rather than the full tables or additional analyses. Source values remain separate from presentation code. CSVs are downloadable from figure captions; all figures have alt text. Results describe the paper's evaluated configurations and samples, not current product behavior.

## Reproduction

Run `python3 scripts/build_fvh_blog_figures.py` with Matplotlib installed. Package versions are recorded in `build-environment.txt`. This regenerates four SVGs from CSVs and diagram specifications. The cover is not regenerated by this script. Native text remains searchable in the SVG outputs. No website runtime dependency is added.
